Scope

Solution

The go-to vector should come back at the command speed. A length that does not match is flagged on the contact panel.

Transport

The board is BLE only, so there is nothing to pair in the OS Bluetooth settings — the page connects to ZYBO-RADAR itself. It accepts one receiver at a time; when another machine already holds it, use the Python bridge on that machine instead.

Wire protocol

ASCII, comma separated, one frame per line, every field an integer.

Getting data in

Bluetooth LE connects to ZYBO-RADAR over the Nordic UART service straight from Chrome. The board is not paired in the OS Bluetooth settings — the page connects to it directly, and ASCII arrives in 20-byte pieces that are joined back into lines on each newline. Serial port opens a USB CDC or virtual COM port at the baud in Settings.

The board takes one receiver at a time. If it is already connected to another machine, nothing else can reach it — that machine has to share what it is getting. Run bridge.py --ble --host 0.0.0.0 there and it serves both this page and a WebSocket on port 8787 to everyone on the network; each viewer opens the page from that machine and picks Python bridge. One radio connection, any number of screens.

With no board at all, Replay plays a saved log one line every 100 ms, which behaves exactly like a live link, and Synthetic feed generates fresh rows in the same wire format.
